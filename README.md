# 房屋租赁安全责任书在线签署系统

这是一个基于Web的房屋租赁安全责任书在线签署系统，支持手机端操作。

## 功能特点

- 📱 响应式设计，完美适配手机
- 📷 支持相机拍照上传
- ✍️ 手写签名功能
- 📄 生成签署凭证图片
- 📱 微信扫码即可使用

## 部署指南

### Gitee Pages 部署
1. 登录Gitee并创建新仓库
2. 上传此HTML文件
3. 进入仓库 → 服务 → Gitee Pages
4. 启用Pages服务
5. 获取访问链接

### GitHub Pages 部署
1. 创建GitHub仓库
2. 上传文件
3. Settings → Pages → 选择main分支
4. 获取访问链接

## 使用说明

1. 用户扫码打开网页
2. 填写房屋租赁双方信息
3. 滚动阅读责任书并确认
4. 手写签名
5. 拍照上传证件
6. 确认签署
7. 长按保存签署凭证图片

## 注意事项

- 确保服务器支持HTTPS
- 相机功能需要HTTPS环境
- 建议使用国内CDN加速
